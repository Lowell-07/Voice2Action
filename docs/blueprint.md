# **App Name**: Voice2Action

## Core Features:

- State-Based Issue Display: Displays problems reported and solved in a selected Indian state, categorized by department, with multimedia attachments. The search box suggests available states.
- Interactive Map Exploration: Uses OpenLayers to display issues on a map, with color-coded dots indicating issue popularity. A GPS tool enables users to zoom to their current location.
- Problem Reporting with Multimedia: Logged-in users can report problems with GPS location, photo/video uploads (compressed via TinyPNG), optional voicemail and text description. Reports are categorized by Civic Service Department and Issue Type.
- Admin Report Approval Tool: Admin users can log in to view and approve user-submitted reports, routing them to relevant department dashboards.
- Personalized User Profile: Logged-in users have a profile page displaying their profile photo, personal details, and activity statistics (issues reported, resolved, pending).
- GPS Location Suggestions: Suggest location names based on GPS coordinates, offering the user a quicker alternative to manual selection, enhancing the tool's usability on mobile devices.
- Mobile OTP Login: Secure login system using mobile number and OTP verification for accessing report and profile sections.

## Style Guidelines:

- Primary color: Forest green (#386641) to evoke trust, growth, and community.
- Background color: Light beige (#FAF8F1), providing a neutral, clean backdrop.
- Accent color: Mustard yellow (#A78544) to highlight key actions and information.
- Headline font: 'Playfair', a modern sans-serif font for headlines. Body font: 'PT Sans', a versatile sans-serif font.
- Use a set of consistent, outline-style icons to represent different report categories and actions, providing a clean and modern aesthetic.
- Implement a responsive layout to ensure optimal viewing and interaction across devices (desktop, tablet, mobile). Utilize a grid system for consistent content placement.
- Use subtle transitions and animations to provide feedback on user interactions, like button presses, form submissions, and content loading. Avoid distracting or unnecessary animations.
